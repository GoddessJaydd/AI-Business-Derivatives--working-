# StarNest API Catalog

## How to use
Start with [selection rules](API_SELECTION_RULES.md), then search the [public API directory](https://github.com/public-apis/public-apis) and the relevant platform's official documentation. Keep this catalog focused on StarNest needs rather than copying the directory.

The rows below are research categories, not verified providers. No API has been selected, installed, or live-tested as part of this setup. Pricing, access, and commercial rights remain unverified until documented for an actual candidate.
